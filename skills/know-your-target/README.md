# Know your target

Use these skills to establish what belongs to the target and which systems are reachable before
deeper surface analysis.

- [`organization-and-roots`](organization-and-roots.md) — map the organization and owned apexes.
- [`subdomain-enumeration`](subdomain-enumeration.md) — enumerate and deduplicate hostnames.
- [`dns-analysis`](dns-analysis.md) — classify DNS records, wildcard behavior, and routing leads.
- [`asn-and-ip-discovery`](asn-and-ip-discovery.md) — attribute netblocks and IP space.
- [`live-host-validation`](live-host-validation.md) — validate resolved names and vhost candidates.
- [`port-and-service-discovery`](port-and-service-discovery.md) — identify exposed services.
- [`http-probing`](http-probing.md) — establish the live web estate and HTTP behavior.
