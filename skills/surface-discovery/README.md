# Surface discovery

Use these skills after selecting one host or a target-brain host set to expose the application
surface that later testing can reason about.

- [`technology-fingerprinting`](technology-fingerprinting.md) — identify edge and origin stacks.
- [`component-inventory`](component-inventory.md) — record components and version precision.
- [`url-collection`](url-collection.md) — collect and reduce historical and observed URLs.
- [`content-discovery`](content-discovery.md) — discover new paths with target-aware calibration.
- [`javascript-analysis`](javascript-analysis.md) — extract routes, parameters, and secret-shaped leads.
- [`api-discovery`](api-discovery.md) — recover protocols, operations, and contracts.
- [`parameter-discovery`](parameter-discovery.md) — identify accepted parameters and parser behavior.
